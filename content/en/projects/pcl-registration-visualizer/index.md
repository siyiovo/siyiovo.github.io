## Overview

The repository provides a visualization tool for inspecting custom point-cloud registration algorithms and includes a runnable example based on PCL `IterativeClosestPoint`.

## Documented interactions

- Press `n` in the visualizer to inspect the next iteration result.
- Configuration includes keypoint mode, neighborhood size, curvature threshold, and iteration parameters.
- The repository documents PCL, Eigen, and ROS workspace build requirements.
